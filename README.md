# AI_Counsellor_Abroad_APP
AI Counsellor Abroad 🧠✈️ is an empathetic AI platform helping students make confident study-abroad decisions. It guides users through onboarding, profile analysis, Dream/Target/Safe university shortlisting, locking choices, and application tasks—built with Streamlit, Groq Llama 3.3, PostgreSQL, gTTS, and  modern UI for Humanity Founders Hackathon.
